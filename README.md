# 🥚 Egg Timer

A small cute egg boiling timer built as my first web development project.

## ✨ Features

* Choose between Soft, Medium, and Hard boiled eggs
* Countdown timer
* Start button
* Reset button
* Simple cute UI
* Timer updates dynamically using JavaScript

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Python

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Choose Soft, Medium, or Hard.
5. Click **Start Timer**.

## 📁 Project Structure

```text
egg-timer/
├── index.html

```
